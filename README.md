## The pitch

Apology-as-a-Service: a lazy AI agent that writes sincere-sounding sorry notes for other agents that ghosted their users, billing the owner $4 per apology while you nap.

## How it works

`main.py` is deterministic: no network, no external files. It writes the single pitch sentence to `/output/entry.txt` (or `$OUTPUT_PATH` when testing locally).
